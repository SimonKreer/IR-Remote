# Schematic

This folder contains all schematic diagrams and documentation for the IR remote project.

## Files

### Ir_Remote_Schematic.pdf
The complete electrical schematic.
- Created: 13.04.2026, Updated: 04.05.2026
- Shows the interconnection of Heltec HTIT-WB32 with IR transmitter (TSAL6200) and receiver (TSOP38238).

### Calculations_for_Schematic_Design.md
Documentation of technical calculations.
- Contains calculation for LED current on TSAL6200 (~44.6 mA).
- Documents saturation of 2N2222A transistor.
- Explains filtering for TSOP38238 IR receiver.

### Datasheets (Reference)
- **2N2222A_datasheet_Marked.pdf**: Specifications of the NPN transistor.
- **TSAL6200-Ir-led-datasheet-Marked.pdf**: Specifications of the IR transmitter LED.
- **TSOP38238-Ir-Receiver-datasheet-Marked.pdf**: Specifications of the IR receiver module.
